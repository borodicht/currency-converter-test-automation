# Автоматизация тестирования банковского конвертера

Проект выполняет регрессионные проверки банковского конвертера и формирует подробные результаты для Allure Report и Allure TestOps проекта 11.

## Что входит

- 19 тестов, привязанных через `@AllureId` к кейсам 2624–2642.
- 14 успешных и 5 выявляющих продуктовые дефекты тестов.
- Русские бизнес-названия, Epic, Feature, Story, Severity, Owner и ссылки.
- Требования и тестовые данные как параметры.
- Пошаговое выполнение и вложения: предусловия, JSON, ожидаемый и фактический результат, SVG-состояние UI.
- Окружение, категории дефектов и информация о запуске.

## Локальный запуск и отчёт

```bash
./run-regression.sh
allure open target/allure-report
```

`run-regression.sh` завершается успешно после генерации отчёта, хотя Maven фиксирует пять выявленных продуктовых дефектов.

## Загрузка в Allure TestOps

Передайте API-токен только через защищённую переменную `ALLURE_TOKEN`, затем:

```bash
./upload-testops.sh
```

По умолчанию используются `https://allure.pflb.ru`, проект `11` и результаты `target/allure-results`. Токен в проекте не хранится.
